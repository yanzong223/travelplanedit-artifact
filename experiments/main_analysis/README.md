# Main Analysis Data

This directory contains only the paper-facing main results table.

- `tables/main_results_table.csv`: machine-readable main table rows.
- `tables/main_results_table.md`: Markdown rendering of the same rows.

Rendered figures, plotting scripts, raw per-run benchmark reports, run registries, analyst notes, auxiliary appendix tables, and intermediate rollups are intentionally omitted from the public artifact.
