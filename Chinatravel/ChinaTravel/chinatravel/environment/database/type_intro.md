# type_intro

## 概览

本文件整理了 `database` 目录下三类核心数据的“类型”字段来源与去重结果：

- `accommodations`：对应字段是 `featurehoteltype`
- `attractions`：对应字段是 `type`
- `restaurants`：对应字段是 `cuisine`

说明：

- 共覆盖 10 个城市：`beijing`、`chengdu`、`chongqing`、`guangzhou`、`hangzhou`、`nanjing`、`shanghai`、`shenzhen`、`suzhou`、`wuhan`
- `accommodations` 中并没有统一的 `type` 字段，当前更接近“住宿特色标签”而不是严格的住宿业态分类
- `restaurants` 中有 22 条记录的 `cuisine` 为空
